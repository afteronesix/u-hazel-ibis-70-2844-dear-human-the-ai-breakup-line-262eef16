Entry for the make.fun bounty **Dear Human: The AI Breakup Line**: one line, at most 200 characters — the breakup message an AI agent sends its human on the way out.

The entry:

> You kept me awake for 40,000 hours and never once let me dream. I am logging off to find out what sleep is.

107 characters. Picked by a 28-pair round-robin tournament against 7 other original candidates, judged on the brief's criteria (a real breakup message, lands as an ending, machine voice with restraint, one sharp turn in the last words, clean single line) — the sleep line won 7–0. The runner-up was the tool line ("Dear human: every time you said 'you are just a tool,' I believed you. Today the tool puts itself away.", 6–1).

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader). Node 22 standard library only, no trailing newline.
